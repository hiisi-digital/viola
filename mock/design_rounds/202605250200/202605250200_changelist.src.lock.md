Verification: `grep -q "pub struct DiscoveredFilePaths" mock/crates/viola-core/src/resources.rs && grep -q "pub unsafe fn push" mock/crates/viola-core/src/resources.rs`.

Host-shim-populated input Resource. `paths: UnsafeCell<[Str; MAX_DISCOVERED_FILES]>` initialised to `[Str::default(); N]`, `paths_len: Cell<arvo::USize>`. Simpler than ExtensionHost because Str is `Copy` and has a default sentinel; no MaybeUninit needed. `unsafe impl Sync` four-invariant SAFETY note. `push` is `pub unsafe fn` with `# Safety` clause naming the four invariants the caller must uphold (temporal contract, single-writer, no-Write-by-any-WU, cap bound). `paths_len` and `path_at` are safe read accessors.
