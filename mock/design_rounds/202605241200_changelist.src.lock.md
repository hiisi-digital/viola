# Source changes

## `crates/viola-deno-runtime/src/lib.rs`

Rewrite as the minimal crate root: doc header, module declarations, capacity constants, runner / grammar / lint provider statics, init / shutdown handler structs, `#[export_extension]`. Drops the prior monolithic 941-line file.

Add `// lint:allow(no-std)` near the crate root doc comment (within the first 30 lines) to escape the `crate root is missing #![no_std]` check. The crate is fundamentally a subprocess host; making it literally `#![no_std]` is contradictory to its identity.

## `crates/viola-deno-runtime/src/error.rs` (new)

`DenoRuntimeError` typed enum (21 variants) replacing every prior `Result<_, String>` at the IPC layer. Carries `label()` for stderr reporting and `report()` for the bridge's error-path output.

## `crates/viola-deno-runtime/src/path.rs` (new)

`PathBuf64`: fixed-cap UTF-8 path buffer replacing `std::path::PathBuf` at host-owned positions. Drops to `&Path` only at the std boundary calls. Carries `from_str`, `as_bytes`, `as_str`, `as_path`.

## `crates/viola-deno-runtime/src/arena.rs` (new)

`Arena`: fixed-cap bump arena holding owned bytes that `Diagnostic` records reference via `BytesRef`. Replaces the prior `Vec<Vec<u8>>` blobs plus `Vec<Diagnostic>`. Sizes: `ARENA_BYTES = 128 KiB`, `MAX_DIAGS = 512`. Carries `new`, `clear`, `intern`, `push_diag`, `diagnostics_ptr`.

## `crates/viola-deno-runtime/src/encoder.rs` (new)

`FrameWriter`: stack-allocated 64 KiB JSON output buffer. Hand-rolled JSON emitter for the host-to-worker direction. `build_lint_request` writes `{"op":"lint","scope":{...}}`. `build_shutdown_request` writes `{"op":"shutdown"}`. Replaces `serde_json::to_writer`. The full JSON string escape set (`\"`, `\\`, control characters, `\b`, `\f`, `\n`, `\r`, `\t`) handled inline.

## `crates/viola-deno-runtime/src/parser.rs` (new)

`ParsedDiag` and `ParsedMessage` carriers for the worker-to-host wire shape. `parse_message` scans for the leftmost top-level key (`done` / `err` / `diag`) and dispatches to a field-by-field parse for the diag case. `parse_json_string`, `parse_json_u32`, `find_key`, `skip_ws`, `trim_ws` are the JSON-parse primitives. `read_line_into` is the no-alloc replacement for `BufReader::read_line` (uses `BufRead::fill_buf` + `consume` against a stack buffer). Replaces `serde_json::from_str`.

## `crates/viola-deno-runtime/src/worker.rs` (new)

`WorkerState`: live subprocess handle holding `Child`, `Option<ChildStdin>` (`Option` is the std-side typed slot for the `take()` pattern in `Drop`), `BufReader<ChildStdout>`, `bridge_path: PathBuf64`, `arena: Arena`, `encode_buf: FrameWriter`, `line_buf: [u8; LINE_CAP]`. Owns the deno subprocess lifecycle.

`write_bridge_to_temp` writes the embedded `bridge.ts` to a temp path. `spawn_worker` invokes `deno run --allow-all <bridge> <config>` and captures stdin/stdout pipes. `config_path_from_bytes` canonicalises the user's `viola.config.ts` path into a `PathBuf64`. `lint_evaluate_inner` is the per-call IPC roundtrip (emit lint request, parse lines until `done`/`err`/N diag records).

`lint_evaluate` is the cdylib export reached via the `LintEvaluateVtable` trampoline. `WORKER_STATE` is the global `Mutex<Option<WorkerState>>` singleton.

Each `use std::*` import line carries `lint:allow(forbidden-imports, no-std)` with `tracked: #197` and a documented rationale for the irreducible boundary point. The same applies to the inline `std::process::id()` call inside `write_bridge_to_temp`.

## `crates/viola-deno-runtime/Cargo.toml`

Drop `serde` and `serde_json` from `[dependencies]`. The hand-rolled JSON emitter and parser replace both.
