# What lands in source

In `viola-core/src/resources.rs`:

- `MAX_DIAGS_PER_LINT: usize` const. Workspace-default `64`. Each `RunLint<L>`
  writes up to that many diagnostics into a per-L disjoint row range of
  `Column<WuDiagnostic>` (slots
  `[L * MAX_DIAGS_PER_LINT, (L + 1) * MAX_DIAGS_PER_LINT)`). Pre-1.0; revisable.
- `LintSlots` Resource. Slot-to-plugin mapping:
  `UnsafeCell<[arvo::Cap; MAX_LINTS]>` plus `Cell<arvo::USize>` populated count.
  Slot L holds the host_idx of the lint plugin at that slot when populated;
  sentinel `arvo::Cap(arvo::USize(usize::MAX))` for "no plugin at this slot".
  `unsafe impl Sync` mirrors DiscoveredFilePaths and FileEntryBuffer.
  `pub unsafe fn push(&self, host_idx: arvo::Cap) -> arvo::Cap` host-shim seam
  with the four-invariant `# Safety` clause; safe `slot_at(L)` returning
  `Maybe<arvo::Cap>` (Maybe::Isnt for sentinel).
- `LintConfigBuffer` Resource. Per-slot config bytes:
  `UnsafeCell<[viola_plugin_abi::BytesRef; MAX_LINTS]>` plus `Cell<arvo::USize>`
  populated count. Slot L holds the BytesRef into the ViolaCfg arena's bytes for
  that lint's config block. Same `unsafe impl Sync` contract.
  `pub unsafe fn push(&self, bytes: BytesRef) -> arvo::Cap` host-shim seam; safe
  `config_at(L) -> BytesRef` (returns `BytesRef::EMPTY` for slots past the
  populated count, matching the ABI "empty config = absent" convention).

In `viola-core/src/invoke.rs`:

- `lint_vtable_from_library(&hilavitkutin_linking::Library) -> Maybe<&'static LintEvaluateVtable>`.
  Parallels Slice 5b's `runner_vtable_from_library`. Walks the descriptor's
  provider table looking for `PROVIDER_LINT_EVALUATE`.

In `viola-core/src/wus/run_lint.rs`:

- Module docstring fix: drop the stale Slice 6a reviewer-nit reference to
  `arvo::Cap<MAX_LINTS>`-bounded variant. Replace with a paragraph naming the
  Slice 6b supporting Resources and the disjoint-slot-range write strategy. Pin
  the column-capacity contract: consumers MUST size `Column<WuDiagnostic>` to at
  least `MAX_LINTS * MAX_DIAGS_PER_LINT` slots.
- AccessSet refinement: Read extends to include `Resource<ExtensionHost>`,
  `Resource<LintSlots>`, `Resource<LintConfigBuffer>`. Existing `Column<Nam>`
  Read stays. Write stays `Cons<Column<WuDiagnostic>, Empty>`. COMMUTATIVE flag
  set in Slice 6a stays.
- Body: reads `LintSlots::slot_at(L)`. If `Maybe::Isnt` (no plugin at this
  slot), returns silently. Otherwise gets `&Library` via
  `ExtensionHost::library_at`, calls `lint_vtable_from_library`. On vtable
  resolution failure, writes one
  `WuDiagnostic { source: WuDiagnosticSource::RunLint }` at slot
  `L * MAX_DIAGS_PER_LINT` and returns. On success, reads `NamPayload` from
  `Column<Nam>` slot zero, reads `LintConfigBuffer::config_at(L)` for the
  per-slot bytes, builds a stack `DiagnosticBatch` placeholder, calls `evaluate`
  FFI with `host_ctx = null_mut()`. On `AbiStatus != Ok`, writes the failure
  diagnostic. On success, projects up to `MAX_DIAGS_PER_LINT` returned
  `Diagnostic` records into the per-L row range of `Column<WuDiagnostic>` (one
  WuDiagnostic per FFI Diagnostic; Str fields stay `Str::default()` per the
  Slice 6a deferral on the LintFinding carrier).
- SAFETY note on the per-batch `Diagnostic` read explicitly names the
  plugin-side precondition: "Plugin's evaluate contract asserts entries is valid
  for read of `len` Diagnostic records when AbiStatus::Ok is returned."

In `viola-core/tests/run_lint.rs`:
