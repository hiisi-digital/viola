## CHANGE: const `MAX_DIAGS_PER_LINT: usize = 64` ADDED to viola-core resources

File: `mock/crates/viola-core/src/resources.rs` Verification:
`grep -q "pub const MAX_DIAGS_PER_LINT" mock/crates/viola-core/src/resources.rs`.

Workspace-default cap for per-`RunLint<L>` diagnostic output. Each L writes to
slots `[L * MAX_DIAGS_PER_LINT, (L + 1) * MAX_DIAGS_PER_LINT)` of
`Column<WuDiagnostic>`. Consumers MUST size the column to at least
`MAX_LINTS * MAX_DIAGS_PER_LINT` slots.

## CHANGE: function `RunLint::execute` BODY filled

File: `mock/crates/viola-core/src/wus/run_lint.rs` Verification:
`! grep -q "unimplemented!.\"Slice 6" mock/crates/viola-core/src/wus/run_lint.rs && grep -q "vtable.evaluate" mock/crates/viola-core/src/wus/run_lint.rs`.

Body reads `LintSlots::slot_at(L)`. Returns silently on `Maybe::Isnt`. Otherwise
gets `&Library` via `ExtensionHost::library_at`, resolves the lint vtable via
`lint_vtable_from_library`. On vtable resolution failure, writes one
`WuDiagnostic { source: WuDiagnosticSource::RunLint }` at slot
`L * MAX_DIAGS_PER_LINT`. On success, reads `Nam` from `Column<Nam>` slot zero,
reads `LintConfigBuffer::config_at(L)`, builds an empty `DiagnosticBatch`, calls
`evaluate` FFI with `host_ctx = null_mut()`. On `AbiStatus != Ok`, writes the
failure diagnostic. On success, projects up to `MAX_DIAGS_PER_LINT` returned
`Diagnostic` records into the per-L disjoint row range of
`Column<WuDiagnostic>`. The unsafe-block SAFETY note on the per-batch entry read
names the plugin-side precondition explicitly. Column-capacity contract enforced
via `debug_assert!` at the writer boundary.
