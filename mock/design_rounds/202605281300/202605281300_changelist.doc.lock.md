# Doc changelist: round 202605281300

**Phase:** DOC (living until lock) **Topic:**
`202605281300_topic.nam-v1-1-0-schema.md` **Scope:** NAM v1.1.0 ABI surface in
`viola-plugin-abi`: version const, `NamNode` struct, `NamFileEntry.nodes`

Rust node-kind id table. No host serialiser (lands with #220).

## What ships

Decision 2 (Option b): the host serialises the parsed AST into a flat
`#[repr(C)]` `NamNode` array per file, carried through NAM; cdylibs walk it by
index without linking tree-sitter. This slice ships the ABI both the serialiser
(#220) and the bucket-2 cdylibs (#617) compile against. Node kinds are named by
stable ids from a workspace-canonical Rust table.

## CHANGE: fn `nam_file_nodes` ADDED

`pub fn nam_file_nodes<'a>(entry: &'a NamFileEntry) -> Option<&'a [NamNode]>`:
`None` when `entry.nodes.data` is null (no tree), else `Some(slice)` with
`count = entry.nodes.len.0 / size_of::<NamNode>()`. Safe fn (the borrow is tied
to the entry reference); the unsafe slice construction is justified by the
entry's carrier contract.
