# Why this round exists

Round 202605281300 added `NamVersion::V1_1_0`, `NamNode`, the
`NamFileEntry.nodes` carrier, the `nam_file_nodes` accessor, the widened
`nam_file_entries` gate, and the `node_kind` id table. The design doc's NAM
section documents only `NamPayload` and `NamVersion`; it never described
`NamFileEntry` or the walk accessor even at v1.0.0. The `docs=design` contract
wants the living design doc to describe the shipped surface, so this round
brings the NAM section up to date.

# What lands

- `viola-plugin-abi/DESIGN.md.tmpl`: the NAM section gains subsections for
  `NamFileEntry` (now four fields including `nodes`), `NamNode`, the `node_kind`
  id table, and the `nam_file_entries` / `nam_file_nodes` accessors, with a note
  that the v1.x entry layout is shared and the host serialiser lands with the
  runner plugin.
