# Why this round exists

PR #25 (Slice 2a source) merged at viola dev `3a84db1` with seven undocumented viola-config types: `ConfigBytes`, `ConfigArena`, `ViolaConfigOwned`, `ViolaCfg`, `PluginEntryOwned`, `GateOwned`, `RuleOwned`, `PartialRuleOwned`. The pre-push gate's `undocumented-type` lint blocked the merge until SHAME entries unblocked it. The SHAME route is the gate's own documented escape hatch; it is not a permanent doc surface. The right doc surface is `DESIGN.md.tmpl` per the workspace's mock-workspace rule.

The Slice 2a SRC CL committed CHANGE blocks for these doc sections but did not land them, because the locked DOC CL (one phase earlier) had already frozen the template edit window per the `changelist-doc-gate` lint. The lint correctly prevents drive-by template edits in IMPL phase; the corollary is that template edits must land during the DOC phase of their owning round. Slice 2a's DOC phase did not author the actual sections (it committed only the planning artefact), so the source-side gap stood at lock time.

PR #26 (round 1900 close) reviewer specifically flagged this gap and recommended a follow-up DOC round as the next unit of work, not deferred behind other slices. This round is that follow-up.
