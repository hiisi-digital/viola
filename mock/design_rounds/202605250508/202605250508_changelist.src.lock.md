The new `impl ConfigBytes` block carries `pub fn empty() -> Self` returning the
empty buffer (`bytes: [0u8; CONFIG_MAX_BYTES]`,
`len: arvo::Cap(arvo::USize::ZERO)`). The existing
`impl Default for ConfigBytes` keeps but its body shrinks to `Self::empty()`.

for callers that need the trait shape (builder patterns, derives). Closes
reviewer's finding 2 by making the call-site intent explicit:
`ConfigBytes::empty()` reads as "not-yet-populated placeholder" where
`ConfigBytes::default()` would read as "the semantically meaningful default
config".
