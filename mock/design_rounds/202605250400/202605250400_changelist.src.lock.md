## CHANGE: const `EMPTY_FILE_ENTRY` ADDED to viola-core resources

File: `mock/crates/viola-core/src/resources.rs` Verification:
`grep -q "const EMPTY_FILE_ENTRY" mock/crates/viola-core/src/resources.rs`.

Crate-private const initialising a `viola_plugin_abi::FileEntry` with
`BytesRef::EMPTY` for path/language/hash and zero for size_bytes. Used by
`FileEntryBuffer::new()` to const-init the slot array.

## CHANGE: struct `FileEntryBuffer` ADDED to viola-core resources with `pub unsafe fn push` host-shim seam

File: `mock/crates/viola-core/src/resources.rs` Verification:
`grep -q "pub struct FileEntryBuffer" mock/crates/viola-core/src/resources.rs && grep -q "pub unsafe fn push" mock/crates/viola-core/src/resources.rs`.

Host-shim-populated input Resource.
`entries: UnsafeCell<[FileEntry; MAX_DISCOVERED_FILES]>` initialised to
`[EMPTY_FILE_ENTRY; N]`, `entries_len: Cell<arvo::USize>`. Mirrors
`DiscoveredFilePaths`'s four-invariant Sync contract. `push` is `pub unsafe fn`
with `# Safety` clause naming the four caller-asserted invariants;
`entries_len(&self)` and `entries_ptr(&self) -> *const FileEntry` are safe read
accessors. The `entries_ptr` accessor surfaces the raw pointer needed for
`RunScope.files`.

## CHANGE: method `ExtensionHost::loaded_count` ADDED to viola-core resources

File: `mock/crates/viola-core/src/resources.rs` Verification:
`grep -q "pub fn loaded_count" mock/crates/viola-core/src/resources.rs`.

New safe accessor returning the populated library-slot count. RunRunner uses
this to bound its `Column<PluginEntry>` iteration (LoadPlugins writes one
PluginEntry row per ExtensionHost push, so the column length matches
loaded_count by construction).

## CHANGE: function `runner_vtable_from_library` ADDED to viola-core/src/invoke.rs

File: `mock/crates/viola-core/src/invoke.rs` Verification:
`grep -q "pub fn runner_vtable_from_library" mock/crates/viola-core/src/invoke.rs`.

New crate-public helper:
`runner_vtable_from_library(&hilavitkutin_linking::Library) -> Maybe<&'static RunnerExecuteScopeVtable>`.
Walks the descriptor's provider table per the Slice 3 `resolve_descriptor`
pattern, delegates tag/version validation to
`hilavitkutin_extensions::validate_descriptor`, finds the runner provider,
returns the casted vtable. Returns `Maybe::Isnt` on every failure path. The
pre-#254 `runner_vtable(&Extension)` stays alongside.

## CHANGE: AccessSet `RunRunner::Read` and `Write` REFINED

File: `mock/crates/viola-core/src/wus/run_runner.rs` Verification:
`grep -q "Cons<Resource<CiState>" mock/crates/viola-core/src/wus/run_runner.rs && grep -q "Cons<Column<Nam>, Cons<Column<WuDiagnostic>" mock/crates/viola-core/src/wus/run_runner.rs`.

## CHANGE: function `RunRunner::execute` BODY filled

File: `mock/crates/viola-core/src/wus/run_runner.rs` Verification:
`! grep -q "unimplemented!.\"Slice 5" mock/crates/viola-core/src/wus/run_runner.rs && grep -q "execute_scope" mock/crates/viola-core/src/wus/run_runner.rs`.

Body resolves the runner plugin (walks `Column<PluginEntry>` finding the first
entry with the runner-role bit set, gets `&Library` via
`ExtensionHost::library_at`, extracts the vtable via
`runner_vtable_from_library`), builds `RunScope` on stack with Slice
5a-documented placeholders (workspace_root = `BytesRef::EMPTY`, surface =
`RunSurface::Cli`, ci from `CiState.is_ci`, host_ctx = `null_mut`), calls
`execute_scope` FFI, writes the returned `NamPayload` into `Column<Nam>` at slot
zero on success. Failures (runner not found, vtable resolution failed, AbiStatus
!= Ok) emit `WuDiagnostic { source: WuDiagnosticSource::RunRunner }` at slot
zero of `Column<WuDiagnostic>`.
