# Design call: host-shim seam, in-WU FFI invocation, no FileEntry enrichment

Slice 5b body operates against host-shim-populated input Resources (`Resource<DiscoveredFilePaths>` from Slice 4 already on dev; `Resource<FileEntryBuffer>` lands in this round). RunRunner reads `Resource<FileEntryBuffer>` to get a pointer into the FFI-shaped array, builds `RunScope` on stack pointing into that buffer, calls `execute_scope` FFI.

Initial Slice 5b ships these placeholders (each tracked in BACKLOG, deferring to future slices):
- `workspace_root: BytesRef::EMPTY` (BACKLOG: Workspace path Str-to-bytes resolution for FFI; waits on Slice 2b host-shim long-lived interner).
- `surface: RunSurface::Cli` (BACKLOG: Resource<RunSurface> and CiState surface field; waits on viola-cli host-shim shape decision).
- `host_ctx: core::ptr::null_mut()` (BACKLOG: host_ctx model for FFI plugin callbacks; trigger Slice 8 host-shim wire-up).
- `FileEntry.language`, `FileEntry.hash`, `FileEntry.size_bytes` all default to `BytesRef::EMPTY` / `0` (BACKLOG: FileEntry enrichment for RunScope; waits on host-shim filesystem walker upgrades).

Plugins must tolerate empty workspace_root and empty FileEntry enrichment fields per the ABI documentation. Slice 5b proves the FFI infrastructure works end-to-end; subsequent slices fill the placeholders without restructuring the body.

# Runner plugin resolution

Slice 5b walks `Column<PluginEntry>` finding the first entry with the runner-role bit set (`PROVIDER_RUNNER_EXECUTE_SCOPE` projects to bit 0 per Slice 3's `resolve_descriptor`). Uses that entry's `host_idx` to get `&Library` via `ExtensionHost::library_at`. Calls the new `runner_vtable_from_library` helper to walk the descriptor's provider table and return `&'static RunnerExecuteScopeVtable`.

The helper lives in `viola-core/src/invoke.rs` alongside the existing pre-#254 `runner_vtable(&Extension)`. Both ship; the new one takes `&Library` and operates on the descriptor walk directly. The pre-#254 helper drops in Slice 8 when `pipeline::run` and `Extension` types delete.

# AccessSet refinement

Slice 1 declared `Read = Cons<Column<FileInfo>, Empty>` and `Write = Cons<Column<Nam>, Empty>`. Slice 5b body needs:

- Resource<CiState> Read (to project is_ci into RunScope.ci)
- Resource<ExtensionHost> Read (for library_at lookup)
- Column<PluginEntry> Read (to find the runner)
- Resource<FileEntryBuffer> Read (to point RunScope.files into the buffer)
- Column<Nam> Write (the projection target)
- Column<WuDiagnostic> Write (failure path)

Slice 1's Column<FileInfo> declaration drops: the body does not consume per-FileInfo records; the FFI-shape array in FileEntryBuffer is what the runner sees. Same logic as Slice 4 reviewer guidance: AccessSet matches body usage. Future filtering or per-file enrichment slices extend at point of consumption.

Final AccessSet:

```
Read = Cons<Resource<CiState>,
       Cons<Resource<ExtensionHost>,
       Cons<Column<PluginEntry>,
       Cons<Resource<FileEntryBuffer>, Empty>>>>
Write = Cons<Column<Nam>, Cons<Column<WuDiagnostic>, Empty>>
```

# What lands in source

In `viola-core/src/resources.rs`: new `FileEntryBuffer` Resource. Fixed-cap array `UnsafeCell<[FileEntry; MAX_DISCOVERED_FILES]>` initialised to `[const { EMPTY_FILE_ENTRY }; N]`, plus `Cell<arvo::USize>` length counter. Mirrors `DiscoveredFilePaths`'s four-invariant Sync contract. `pub unsafe fn push(&self, entry: FileEntry) -> arvo::Cap` with `# Safety` clause naming the four caller-asserted invariants (temporal contract, single-writer, no-Write-by-any-WU, cap bound). Safe `entries_len(&self)`, `entries_ptr(&self) -> *const FileEntry`. The `entries_ptr` accessor surfaces the raw pointer needed for `RunScope.files`.

In `viola-core/src/invoke.rs`: new `runner_vtable_from_library(lib: &Library) -> Maybe<&'static RunnerExecuteScopeVtable>`. Walks the descriptor via the Slice 3 `resolve_descriptor` pattern, finds the runner provider, returns the casted vtable pointer. Returns `Maybe::Isnt` on descriptor missing, descriptor invalid (delegated to `hilavitkutin_extensions::validate_descriptor`), runner provider not found, vtable_ptr null.

In `viola-core/src/wus/run_runner.rs`: AccessSet refinement plus body. Body walks `Column<PluginEntry>` (using the column-reader API; PluginEntry rows have `roles: Mask64` and the runner role is bit 0), gets the first matching entry, resolves through ExtensionHost + Library, builds RunScope on stack, calls FFI with null host_ctx and the in-stack scope, writes one Nam row to slot zero on success or a WuDiagnostic record on failure (descriptor missing, vtable absent, AbiStatus != Ok, runner plugin not found).

In `viola-core/tests/run_runner.rs`: compile-time AccessSet-shape witness via sealed `IsSame<X>` (same pattern as `tests/load_plugins.rs` and `tests/discover_files.rs`).
