## CHANGE: struct `ConfigArena` NEW
File: `mock/crates/viola-config/src/lib.rs`
Verification: `grep -q "struct ConfigArena" mock/crates/viola-config/src/lib.rs && grep -q "impl.*ArenaInterner for ConfigArena" mock/crates/viola-config/src/lib.rs`.

The `ConfigArena<const N: usize>` newtype is a crate-private struct over `[u8; N]` plus a `Cap<N>` cursor. It implements `hilavitkutin_str::ArenaInterner` directly. `hilavitkutin-str` ships no fixed-cap arena primitive (the crate's public surface is `Str`, `StringInterner<A: ArenaInterner>`, `ArenaInterner`, `AsStr`, `IntoStr`, `StaticStrEntry`, `const_fnv1a`, and the static-entries helper; there is no `arena.rs`). `ConfigArena` is the consumer-side implementation of `ArenaInterner` that gives `StringInterner<ConfigArena<N>>` a concrete no-alloc backing.

## CHANGE: pub struct `ViolaConfigOwned` NEW
File: `mock/crates/viola-config/src/lib.rs`
Verification: `grep -q "pub struct ViolaConfigOwned" mock/crates/viola-config/src/lib.rs && grep -q "MAX_PLUGINS" mock/crates/viola-config/src/lib.rs && grep -q "MAX_GATES" mock/crates/viola-config/src/lib.rs && grep -q "MAX_RULES" mock/crates/viola-config/src/lib.rs && grep -q "MAX_PARTIAL_RULES" mock/crates/viola-config/src/lib.rs && grep -q "ARENA_BYTES" mock/crates/viola-config/src/lib.rs`.

`ViolaConfigOwned<const MAX_PLUGINS: usize, const MAX_GATES: usize, const MAX_RULES: usize, const MAX_PARTIAL_RULES: usize, const ARENA_BYTES: usize>` ships with a private `arena: ConfigArena<ARENA_BYTES>` field plus fixed-cap arrays for plugins, gates, rules, and partial rules each paired with a `Cap<CAP>` length tracker. The struct is `'static` because all const params are `'static` and `ConfigArena<N>` carries no borrows.

Slice 2a ships the type with placeholder zero-sized record fields (`pub plugins: [PluginEntryOwned; MAX_PLUGINS]` where `pub struct PluginEntryOwned;`). The per-WU body slices that need a real field shape replace each placeholder with the live shape when they land. The CL does not commit those field shapes here.
