## CHANGE: struct `DiagnosticCounts` ADDED to `viola-core/src/resources.rs`
File: `mock/crates/viola-core/src/resources.rs`
Verification: `grep -q "^pub struct DiagnosticCounts" mock/crates/viola-core/src/resources.rs && ! grep -Eq "^[[:space:]]+populated:" mock/crates/viola-core/src/resources.rs` (the negation matches against a field declaration only; doc comments that describe the dropped field by name do not trip the predicate).

`pub struct DiagnosticCounts { counts: UnsafeCell<[arvo::USize; MAX_LINTS]> }`. **Single field**; no sibling `populated` shared counter (a non-atomic RMW on a shared scalar under the parallel RunLint cohort would be a data race regardless of end-state commutativity). `unsafe impl Sync for DiagnosticCounts` with the four-invariant SAFETY note adapted for the multi-writer RunLint cohort (each L writes only its own slot). `pub unsafe fn set_count(&self, slot: arvo::Cap, count: arvo::USize)` writer-side seam; `pub fn count_at(&self, slot: arvo::Cap) -> arvo::USize` safe reader; `pub fn any_populated(&self) -> arvo::Bool` walks `counts[0..MAX_LINTS]` once and returns Bool::TRUE if any slot is non-zero (32-entry scan; lives entirely on the read side). `Default` impl zeroes the counts array.

## CHANGE: `RunLint<L>::Write` AccessSet EXTENDED in `viola-core/src/wus/run_lint.rs`
File: `mock/crates/viola-core/src/wus/run_lint.rs`
Verification: `grep -q "Cons<Column<WuDiagnostic>, Cons<Resource<DiagnosticCounts>, Empty>>" mock/crates/viola-core/src/wus/run_lint.rs`.

`Write` flips from `Cons<Column<WuDiagnostic>, Empty>` to `Cons<Column<WuDiagnostic>, Cons<Resource<DiagnosticCounts>, Empty>>`. Body acquires a `DiagnosticCounts` resource projection through the Write set alongside the existing Column writer. At every exit point (empty-slot, vtable-failure, evaluate-failure, normal-exit) the body calls `DiagnosticCounts::set_count(arvo::Cap(USize(L)), USize(count))` with the appropriate per-L count: zero on empty-slot, one on each failure (the single failure record), and the projection loop's final count on normal-exit.

## CHANGE: `EmitDiagnostics` FROM Slice 1 unit struct TO generic `EmitDiagnostics<W: EmitWriter>` in `viola-core/src/wus/emit_diagnostics.rs`
File: `mock/crates/viola-core/src/wus/emit_diagnostics.rs`
Verification: `grep -q "pub struct EmitDiagnostics<W: EmitWriter>" mock/crates/viola-core/src/wus/emit_diagnostics.rs`.

`pub struct EmitDiagnostics<W: EmitWriter> { _marker: PhantomData<fn() -> W> }`. The `fn() -> W` carrier makes the struct itself `Send + Sync` regardless of `W`; the thread-safety bound `W: Send + Sync + 'static` lives on the `impl WorkUnit` block. AccessSet: `Read = Cons<Resource<DiagnosticCounts>, Cons<Column<WuDiagnostic>, Empty>>`, `Write = Cons<Resource<DiagnosticSink<W>>, Empty>`. `BuilderInput` impl parallels the Slice 1 stub. Body fills per the topic memo: short-circuits when `any_populated().as_bool() == false` after flushing; otherwise walks `DiagnosticCounts::count_at(L)` for L in 0..MAX_LINTS, walks `Column<WuDiagnostic>` slots `[L * MAX_DIAGS_PER_LINT, L * MAX_DIAGS_PER_LINT + count)`, stages records into a stack-cap array sized `MAX_LINTS * MAX_DIAGS_PER_LINT` with a `StagedRecord` carrier holding the WuDiagnostic plus its `original_slot_index`, sorts via the host-side approximation comparator using insertion sort (stable; comparator is total via the slot-index tiebreaker), walks the sorted records, formats one line per diagnostic, calls `EmitWriter::write_str` per line, calls `flush` at end-of-emit. A `static_assertions::const_assert!` pins the stage array size against MAX_LINTS * MAX_DIAGS_PER_LINT.
