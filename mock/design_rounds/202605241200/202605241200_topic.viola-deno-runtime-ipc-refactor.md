# Why now

PR #15 raised the lint floor to match the hilavitkutin discipline. The intended pressure was a follow-up refactor PR that brings each crate into source compliance. Until that lands, no source-touching PR can push (the whole-tree gate runs on every push). This round is the load-bearing refactor that unblocks viola's source push line.

The op-blessed `--no-verify` for the original install (PR #12) was explicitly one-time-only; this round walks the source through the legitimate TOPIC -> DOC -> SRC ceremony for the first time in viola.
