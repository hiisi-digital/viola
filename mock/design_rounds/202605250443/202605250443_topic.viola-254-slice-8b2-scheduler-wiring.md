## Changes proposed

Slice 8b.2 lands the full scheduler-build chain that proves the AccessSet contracts compile end-to-end. The chain registers every Resource and Column that any of the six WUs declares in its `Read`/`Write` AccessSet, plus the six WUs and 32 `RunLint<N>` instances.

### Source edits (one PR, one round, seven CHANGE blocks for the SRC CL)

1. `mock/Cargo.toml`: add `hilavitkutin` to `[workspace.dependencies]` (git ref) + matching `[patch."ssh://git@github.com/orgrinrt/hilavitkutin.git"]` entry (path override at `../../hilavitkutin/mock/crates/hilavitkutin`).
2. `mock/crates/viola-cli/Cargo.toml`: depend on `hilavitkutin = { workspace = true, features = ["platform-os"] }`. The `platform-os` feature flag is mandatory (engine errors at build time without one of `platform-os` / `platform-std` / `platform-no-os`).
3. `mock/crates/viola-config/src/lib.rs`: add `impl Default for ConfigBytes`. Default value is the empty buffer (`bytes: [0u8; CONFIG_MAX_BYTES]`, `len: arvo::Cap(arvo::USize::ZERO)`). Required so viola-cli can `Resource::new(ConfigBytes::default())` at scheduler-builder time without inline bare-numeric literals.
4. `mock/crates/viola-core/src/wus/mod.rs`: promote `pub trait EmitWriter` to `pub trait EmitWriter: Send + Sync`. The `Sync` bound is load-bearing for the `Resource<DiagnosticSink<W>>` Sync contract; without it the scheduler-build typestate cannot prove the Resource Sync.
5. `mock/crates/viola-core/src/wus/emit_diagnostics.rs`: simplify the existing `impl<W: EmitWriter + Send + Sync + 'static> WorkUnit for EmitDiagnostics<W>` to `impl<W: EmitWriter + 'static>` once the supertrait promotion in (4) lands.
6. `mock/crates/viola-cli/src/emit.rs`: add `debug_assert!(remainder.len() <= libc::ssize_t::MAX as usize, "...")` before the `libc::write` call. Closes the Slice 8b.1 reviewer finding flagged as "carry forward to 8b.2".
7. `mock/crates/viola-cli/src/main.rs`: add `#![recursion_limit = "1024"]` at the top (deep cons-list `ContainsAll` typestate proofs overflow the default 128); drop `#[allow(dead_code)]` on `mod emit;` and on the five forward-keepalive items (`EXIT_OK`, `EXIT_PLUGIN`, `HOST_CAPS_EMPTY`, `_BYTES_REF_KEEPALIVE`, `load_plugin`) since 8b.2 uses each natively; add the `register_lints!` declarative macro unrolling 32 `.with(RunLint::<N>)` calls; replace the unix-main `unimplemented!()` stub with the scheduler-build chain that registers 12 Resources, 4 Columns, 5 unit-WUs, and the 32 `RunLint<N>` cohort via the macro.

### The complete AccessSet derivation (the load-bearing research)

Walking every `viola-core/src/wus/*.rs` file's `type Read` and `type Write` AccessSet declarations and accumulating the union:

12 Resources required (referenced in any WU AccessSet):
- `Resource<DiscoveredFilePaths>` (DiscoverFiles Read)
- `Resource<DiagnosticCounts>` (EmitDiagnostics Read, RunLint Write)
- `Resource<DiagnosticSink<W>>` (EmitDiagnostics Write)
- `Resource<Workspace>` (LoadConfig Read)
- `Resource<RunSurface>` (LoadConfig Read)
- `Resource<ConfigBytes>` (LoadConfig Read)
- `Resource<ViolaCfg>` (LoadConfig Write, LoadPlugins Read)
- `Resource<ExtensionHost>` (LoadPlugins Write, RunLint Read, RunRunner Read)
- `Resource<LintSlots>` (RunLint Read)
- `Resource<LintConfigBuffer>` (RunLint Read)
- `Resource<CiState>` (RunRunner Read)
- `Resource<FileEntryBuffer>` (RunRunner Read)

4 Columns:
- `Column<FileInfo>` (DiscoverFiles Write)
- `Column<WuDiagnostic>` (LoadConfig/LoadPlugins/RunLint/RunRunner Write, EmitDiagnostics Read)
- `Column<PluginEntry>` (LoadPlugins Write, RunRunner Read)
- `Column<Nam>` (RunLint Read, RunRunner Write)

Prior session attempt at Slice 8b.2 registered 9 Resources + 4 Columns and missed `ConfigBytes`, `RunSurface`, `ViolaCfg`. The build failed with `Empty: Contains<...>` for those three. The complete enumeration above closes that gap.
