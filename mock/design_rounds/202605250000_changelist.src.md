## CHANGE: new public accessor `ViolaConfigOwned::plugin_path`
File: `mock/crates/viola-config/src/lib.rs`
Verification: `grep -q "pub fn plugin_path" mock/crates/viola-config/src/lib.rs`.

`pub fn plugin_path(&self, i: arvo::Cap) -> notko::Maybe<&str>` on `ViolaConfigOwned`. Returns the `&str` view of `self.plugins[i.0.0].path` by calling the inner `self.arena.arena_resolve(self.plugins[i.0.0].path.id().to_raw() as u32)`. The accessor is `&self`-receiver; the lifetime of the returned `&str` is `&self`-bound per the arena contract. Bounds check: if `i.0.0 >= *self.plugins_len.0`, returns `Maybe::Isnt`. Returning `Maybe<&str>` rather than `""` makes the out-of-bounds case explicit at call sites; `Library::load(b"")` would crash, so a silent empty arm is a real-shape footgun even when the loop is bounded by `plugins_len`.

The `Bits<28, Hot>::to_raw() -> u32` conversion is the natural inverse of the `from_raw` constructor used in `populate_from_borrowed`.

## CHANGE: new type `ExtensionHost`
File: `mock/crates/viola-core/src/resources.rs`
Verification: `grep -q "pub struct ExtensionHost" mock/crates/viola-core/src/resources.rs && grep -q "unsafe impl Sync for ExtensionHost" mock/crates/viola-core/src/resources.rs`.

```rust
pub struct ExtensionHost {
    libs: core::cell::UnsafeCell<[core::mem::MaybeUninit<hilavitkutin_linking::Library>; viola_config::MAX_PLUGINS]>,
    loaded_len: core::cell::Cell<arvo::USize>,
}
```

Plus an `unsafe impl Sync for ExtensionHost` with the four-invariant SAFETY note exactly as the locked DOC CL committed. Plus a `Drop` impl walking `libs[..loaded_len]` calling `MaybeUninit::assume_init_drop` on each slot.

Public surface: `pub const fn new() -> Self` constructs an empty host with `Cell<USize>` zeroed and the `UnsafeCell<[MaybeUninit; N]>` `MaybeUninit::uninit()`-initialised. `pub fn library_at(&self, idx: arvo::Cap) -> &hilavitkutin_linking::Library` reads slot `idx`. The body unconditionally `assert!(idx.0.0 < *self.loaded_len.0)` (release-build retained) before the `MaybeUninit::assume_init_ref` call. The assertion is not a debug-only check: reading an uninitialised `MaybeUninit<Library>` is undefined behaviour, and the assertion is what makes the function sound. Documented in source with an explicit SAFETY note naming the UB. `pub(crate) unsafe fn push(&self, lib: hilavitkutin_linking::Library) -> arvo::Cap` appends one library; SAFETY: caller asserts `loaded_len < MAX_PLUGINS`; bounds-checked at runtime; writes via `(*self.libs.get())[loaded_len].write(lib)` then `self.loaded_len.set(loaded_len + 1)`; returns the 0-based index as `arvo::Cap`.

## CHANGE: `resolve_descriptor` helper added; delegates tag/abi/size checks to `hilavitkutin_extensions::validate_descriptor`
File: `mock/crates/viola-core/src/wus/load_plugins.rs`
Verification: `grep -q "fn resolve_descriptor" mock/crates/viola-core/src/wus/load_plugins.rs && grep -q "hilavitkutin_extensions::validate_descriptor" mock/crates/viola-core/src/wus/load_plugins.rs`.

Crate-private helper:

```rust
fn resolve_descriptor(
    lib: &hilavitkutin_linking::Library,
) -> notko::Outcome<(crate::role::Mask64, hilavitkutin_extensions::AbiVersion), hilavitkutin_extensions::ExtensionError>
```

Body matches the canonical pattern at `hilavitkutin-extensions/src/host.rs:129-158`. `DESCRIPTOR_SYMBOL` is exported as an `extern "C" fn() -> *const ExtensionDescriptor`, not a data static; the helper resolves it via `Library::resolve::<DescriptorFn>(DESCRIPTOR_SYMBOL.to_bytes_with_nul())`, calls the function to obtain the descriptor pointer, null-checks the pointer, and dereferences to `&'static ExtensionDescriptor`. SAFETY: the library author opts into the descriptor contract by exporting the symbol; the host trusts the symbol points at extension-static memory valid for the library's loaded lifetime per the v2 contract. The host keeps the `Library` alive in `ExtensionHost.libs[host_idx]` for the duration of the run, so the `&'static` tightening is sound.

Tag, descriptor-size, ABI-version, name-length, and field-bounds checks delegate to `hilavitkutin_extensions::validate_descriptor(descriptor)`. That helper at `hilavitkutin-extensions/src/host.rs:226` ships the canonical contract checks and returns `Outcome<(), ExtensionError>`; viola should not reinvent the checks per `use-the-stack-not-reinvent.md`. On `Outcome::Err`, this helper passes the `ExtensionError` straight through; the LoadPlugins body emits a `WuDiagnostic { source: PluginLoad }` with the descriptor-level failure as context (host-shim interner deferral still applies for the message body).

On `Outcome::Ok(())`, the helper derives the role `Mask64` from the descriptor's provider table by walking entries and matching `ProviderId` against `PROVIDER_RUNNER_EXECUTE_SCOPE`, `PROVIDER_GRAMMAR_EXTRACT`, `PROVIDER_LINT_EVALUATE` (the three role provider IDs in `viola-plugin-abi`); bit 0 set for runner, bit 1 for grammar, bit 2 for lint. Reads `descriptor.abi_version`. Returns `Outcome::Ok((roles, abi_version))`. The display name `Str` lives at the `LoadPlugins::execute` call site (constructed `Str::default()` until the host-shim interner lands; the deferred work tracked in BACKLOG).

No new `VerifyError` enum: the helper passes `ExtensionError` through. Slice 3 inherits the existing four-variant enum from `hilavitkutin-extensions`.
