the `viola.lint.evaluate.v1` vtable. The evaluator needs to read source bytes
from the NAM payload. The landed `NamPayload` at
`viola-plugin-abi/src/nam.rs:34` is an opaque carrier whose v1.x schema was
deferred. This round commits the v1.0.0 schema.
