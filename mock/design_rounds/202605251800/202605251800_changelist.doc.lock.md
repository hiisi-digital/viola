## What ships

The NAM payload's v1.x schema was deferred at module-doc level. This round
commits the v1.0.0 shape: per-file entries carrying path, language tag, source
bytes. Plugin authors get a typed accessor.

## CHANGE: const `NamVersion::V1_0_0` ADDED

`impl NamVersion` block: `pub const V1_0_0: Self = Self::new(1, 0, 0);`.

Verification:
`grep "pub const V1_0_0" viola/mock/crates/viola-plugin-abi/src/nam.rs` returns
one match.

## CHANGE: type `NamFileEntry` ADDED

File: `viola/mock/crates/viola-plugin-abi/src/nam.rs`. `#[repr(C)]` struct with
`pub path: crate::BytesRef`, `pub language: arvo::USize`,
`pub source: crate::BytesRef`, plus `Send + Sync` SAFETY impls.

Field ordering is alphabetical-by-meaning: `path` identifies the file,
`language` tags its source language, `source` carries UTF-8 bytes. All three are
repr(C) or repr(transparent) so layout is stable.

Verification:
`grep "pub struct NamFileEntry" viola/mock/crates/viola-plugin-abi/src/nam.rs`
returns one match.

## CHANGE: fn `nam_file_entries` ADDED

File: `viola/mock/crates/viola-plugin-abi/src/nam.rs`.
`pub unsafe fn nam_file_entries<'a>(nam: *const NamPayload) -> Option<&'a [NamFileEntry]>`.
Returns `None` on null pointer or version mismatch, `Some(&[])` on null data
with matching version, slice when v1.0.0 + non-null data.
