# Topic: cover the ABI v2 evaluate overflow contract with a test

**Date:** 2026-05-28
**Phase:** TOPIC
**Scope:** Add a host-loader integration test that exercises the `LintEvaluateVtable.evaluate` overflow path: a call with `out_capacity` smaller than the emit count must return `AbiStatus::Internal`, set `*out_len` to the would-have-emitted count, and write no entries. Touches only `viola-core/tests/host_loader.rs`.

**Source TOPIC:** round 202605281000 (ABI v2 host-owned buffer), already locked and merged into this branch.

# Why this round exists

Round 202605281000 shipped the v2 overflow contract: on capacity overflow the plugin writes the first `out_capacity` entries, sets `*out_len` to the count it would have emitted, and returns `AbiStatus::Internal`; the host treats `Internal` as a valid written prefix and records the truncation. The existing `host_loader.rs` test covers only the non-overflow (`Ok`) path. The overflow path is the load-bearing new behavior of the host-owned buffer (it is what lets the host size buffers independently of plugin output), so it earns a dedicated test rather than going unverified.

# What lands

- A second `#[test]` in `viola-core/tests/host_loader.rs` that loads the fixture cdylib, resolves the lint vtable, and calls `evaluate` with `out_capacity = 0`. It asserts the returned status is `ExtensionAbiStatus::Internal` and `*out_len` equals the fixture's emit count (`1`). No entries are read from the buffer (none were written).
